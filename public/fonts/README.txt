Шрифт для имён на брелоках: Roboto Bold.

Источник: https://github.com/googlefonts/roboto-2 (src/hinted/Roboto-Bold.ttf)
Лицензия: Apache License 2.0, текст лежит в ROBOTO_LICENSE.txt.

Файл cyrillic.typeface.json сконвертирован из TTF для three.js FontLoader:
- оставлены ASCII, кириллица U+0400–U+04FF и типографский апостроф;
- контуры перевёрнуты (reverse font direction), как советует facetype.js;
- отверстия букв уменьшены на 0.5% вокруг центра. Без этого нижняя грань
  отверстия в «д» и «Д» лежит на одной прямой с внешним контуром, и Earcut
  оставляет незамкнутые торцы. Сдвиг меньше 0.01 мм на готовом брелоке.

Чтобы заменить шрифт, положите новый typeface.json с тем же именем и проверьте
буквы «д», «Д» и «ё» на замкнутость сетки.
