; Старт-код Marlin 2.x для слайсера (пример для PLA)
;
; Что заменить перед использованием:
;   60  — температура стола первого слоя;
;   210 — температура сопла печати;
;   150 — температура ожидания, чтобы сопло не текло при хоуминге.
;
; Порядок намеренный: сначала стол до рабочей температуры, потом сетка.
; Так BED_MESH_CALIBRATE и UBL измеряют стол в том состоянии, в котором он будет печатать.
; Сопло на 150 °C остаётся тёплым, но не капает на сетку.
;
; Если у принтера нет ABL/UBL, удалите блок сетки и оставьте M420 S1 только
; при наличии сохранённой сетки. Иначе эти команды не нужны.

M140 S60                  ; начать нагрев стола
M104 S150                 ; сопло в режим ожидания
M190 S60                  ; дождаться стола до температуры печати
G28                       ; home всех осей

; --- Сетка стола: выберите ОДИН вариант ---
; A. Новая сетка ABL перед каждой печатью (активный вариант).
;    Занимает несколько минут, зато учитывает текущую поверхность.
BED_MESH_CALIBRATE
M420 S1                   ; включить выравнивание по измеренной сетке

; B. Сохранённая сетка: быстрее для серийной печати.
;    Закомментируйте BED_MESH_CALIBRATE и M420 S1 выше, оставьте только:
; M420 S1

; C. UBL: вместо BED_MESH_CALIBRATE выполните полный цикл.
;    Строки ниже нужно раскомментировать, а вариант A — закомментировать.
; G29 P1                  ; измерить доступные точки
; G29 P3                  ; заполнить пропущенные точки
; M420 S1                 ; включить UBL
; G29 S1                  ; сохранить сетку в слот 1 (по желанию)

M104 S210                 ; сопло на рабочую температуру
M109 S210                 ; дождаться сопла
M107                      ; обдув выключен на время прайма
M82                       ; абсолютный режим экструдера для прайма

G92 E0                    ; обнулить экструдер
G1 Z2.0 F3000             ; подняться над столом
G1 X5 Y20 Z0.3 F5000      ; выйти в начало прайм-линии
G1 X5 Y120 Z0.3 F1500 E12 ; первый проход прайм-линии
G1 X5.4 Y120 Z0.3 F5000   ; сдвиг в сторону
G1 X5.4 Y20 Z0.3 F1500 E24; второй проход рядом
G92 E0                    ; снова обнулить экструдер
G1 Z2.0 F3000             ; подняться перед началом модели

; Проверка после первого запуска:
;   1. Сопло не задевает зажимы и кабель стола.
;   2. Прайм-линия ложится ровно и не выходит за пределы стола.
;   3. Сетка включается без ошибки "Bed Leveling Failed".
;   4. При смене материала обновите три температуры в начале файла.
