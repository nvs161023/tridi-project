# Безопасность локального агента TriDi

Документ для мастера и для того, кто согласует установку программы на
компьютере мастерской. Здесь честно написано, что `TriDiAgent` делает, чего не
делает, куда ходит по сети и как отобрать у него доступ.

Агент — это Python-программа (`agent/main.py`, для фермы собирается в один
файл `TriDiAgent.exe`). Она работает на компьютере рядом с принтерами, потому
что браузер не видит локальную сеть цеха: принтеры стоят на адресах вида
`192.168.x.x`, и команду печати может отдать только программа внутри этой сети.

## Что делает агент

1. **Спрашивает очередь печати.** Раз в 5 секунд `GET
   https://tridi-print.ru/api/agent/tasks` — есть ли задания, которые мастер
   поставил в очередь в разделе «Печать». В запросе уходит только токен в
   заголовке `Authorization: Bearer <AGENT_TOKEN>`.
2. **Скачивает G-code задания.** По ссылке `gcodeUrl` из того же ответа, во
   временную папку `agent/temp/` (рядом с exe). Файл удаляется после печати.
3. **Отправляет файл на принтер и запускает печать** по локальной сети
   мастерской: Moonraker, OctoPrint, PrusaLink, Creality, FlashForge, Elegoo,
   Anycubic, Bambu Lab. Секреты принтера (код доступа, логин-пароль) приходят в
   самом задании и живут в памяти процесса.
4. **Следит за печатью.** Раз в 5 секунд спрашивает состояние принтера и
   отправляет в CRM `POST https://tridi-print.ru/api/agent/status`: прогресс,
   остаток времени, расход пластика, причину отказа. Без этого мастер не увидит
   на доске, что печать встала.
5. **Отправляет пульс.** Раз в 30 секунд `POST
   https://tridi-print.ru/api/agent/heartbeat`, чтобы ферма отличала «агент
   молчит» от «принтер свободен».
6. **По кнопке мастера обходит локальную сеть** (`GET /api/agent/scan-status` →
   обход → `POST /api/agent/discover`) и находит принтеры, чтобы не вбивать их
   адреса вручную. Обход — только подсети из `SCAN_SUBNETS` (по умолчанию сеть
   своего адреса с маской `/24`), и только когда мастер нажал «Найти принтеры в
   сети» или в `.env` включён `SCAN_NETWORK=true`.
7. **Проверяет принтер по кнопке «Проверить связь»** в форме принтера
   (`GET`/`POST /api/agent/probe`): подключается к указанному адресу и
   возвращает модель, серийный номер и возможности.

Всё, что агент отправляет наружу (за пределы локальной сети), — это запросы на
один адрес из `.env` (`CRM_URL`, на боевом сервере `https://tridi-print.ru`) по
HTTPS, порт 443.

## Что агент НЕ делает

- **Не читает личные файлы.** Единственные файлы, которые он открывает: `.env`
  рядом с программой (настройки), скачанный G-code в своей папке `temp/` и
  файлы внутри exe. Ни `Документы`, ни браузерные профили, ни переписка, ни
  буфер обмена не читаются.
- **Не имеет прав администратора.** Запускается от обычного пользователя,
  ничего не ставит в систему, не правит реестр, не создаёт службу Windows,
  не устанавливает обновления. Автозапуск настраивает сам мастер (см.
  AUTOSTART.md), а не программа.
- **Не обращается к другим сайтам.** Никакой аналитики, телеметрии, проверки
  обновлений, облачных хранилищ. Из внешних адресов — только `CRM_URL`.
- **Не отправляет данные никуда, кроме tridi-print.ru.** Ни в мессенджеры, ни на
  почту, ни в сторонние API. Отдельно: у адаптера Bambu Lab есть выход в
  интернет `bambulab.com` **только если** принтер сам настроен на облако
  производителя — агент к этому отношения не имеет и использует MQTT прямо на
  принтер (порт 8883 в локальной сети).
- **Не открывает порты на прослушивание.** У агента нет входящих подключений:
  он только сам звонит в CRM и принтерам, поэтому из интернета к нему
  подключиться нельзя.
- **Не передаёт токены принтеров на сервер.** Секреты принтера идут в одну
  сторону: сервер → агент в задании. Обратно уходят прогресс, ошибки и оценка
  печати.
- **Не пишет токен в журнал.** `AGENT_TOKEN` печатается только длиной — журнал
  агента можно отправить в переписку или в тикет, не выдав ключ.

## Открытый код

Агент не «чёрный ящик»: весь исходный код в открытом репозитории —
<https://github.com/nvs161023/tridi-project/tree/main/agent>.

Точки входа и что смотреть:

| Файл | Что внутри |
|---|---|
| `agent/main.py` | Все запросы к CRM: `/api/agent/tasks`, `status`, `heartbeat`, `discover`, `scan-status`, `probe`. Здесь же цикл опроса и работа с `.env` |
| `agent/scanner.py` | Обход локальной сети и обнаружение принтеров |
| `agent/adapters/registry.py` | Восемь протоколов принтеров, их порты и форматы файлов |
| `agent/build_exe.py` | Сборка `TriDiAgent.exe` (PyInstaller) |

## Как проверить

Собранный exe можно проверить, не запуская его. Все адреса, к которым агент
обращается, лежат в файле открытым текстом:

```bash
# Linux, macOS, Git Bash, WSL
strings TriDiAgent.exe | grep http
```

```powershell
# Windows PowerShell: аналог strings — поиск ASCII по байтам файла
Select-String -Path .\TriDiAgent.exe -Pattern 'api/agent' -AllMatches
```

Что вы увидите: пути вида `/api/agent/tasks`, `/api/agent/status`,
`/api/agent/heartbeat`, `/api/agent/discover`, `/api/agent/probe` — и никаких
посторонних доменов. **Важно:** адрес вашей CRM в exe не зашит, он берётся из
`.env` (`CRM_URL`), поэтому `grep http` покажет только пути роутов, а не сам
домен. Проверить домен можно прямо в файле настроек:

```powershell
Select-String -Path .\.env -Pattern 'CRM_URL'
```

Дополнительно:

- **Сетевой монитор.** Windows: «Монитор ресурсов» → вкладка «Сеть», или
  `netstat -ano | findstr <PID>` — видно, что процесс говорит только с
  `tridi-print.ru` и адресами принтеров.
- **Журнал агента.** Каждый запрос виден строкой в консоли (`Получено 2 задач`,
  `Пульс отправлен`, `CRM недоступна (нет связи)…`). Ничего скрытого.
- **Сборка своими руками.** `python build_exe.py` собирает exe из исходников
  этого репозитория: удобно, если нужен файл с собственной подписью.

## Как отозвать доступ

Доступ агента держится на одном ключе — `AGENT_TOKEN`, он лежит в
`workshop_settings.agent_token` (раздел «Мастерская» → «Интеграции» → карточка
«Локальный агент (Печать)»).

Чтобы отобрать доступ:

1. **Удалить токен из `workshop_settings`** на сайте (очистить значение в
   карточке агента). Новый запрос агента сервер не примет — `401`, и агент
   перестанет получать задания и отправлять статусы. Сразу после этого можно
   сгенерировать новый токен: старые копии exe и `.env` с прежним ключом уже
   бесполезны.
2. **Остановить программу** на компьютере: закрыть окно `TriDiAgent` (или
   `Ctrl+C` в консоли), убрать задачу из Планировщика, если автозапуск
   настраивался.
3. **Удалить файлы**: сам exe, `.env` рядом с ним (в нём токен) и папку `temp/`
   со скачанными G-code.

Отзыв токена не затрагивает принтеры: печать уже запущенных заданий не
прерывается, но новых заданий агент не получит, а прогресс перестанет
обновляться — ферма покажет принтеры как «Офлайн» через две минуты.

## Сетевые порты

Исходящие соединения — только они, входящих агент не открывает:

| Направление | Порт | Протокол | Зачем |
|---|---|---|---|
| `CRM_URL` (tridi-print.ru) | 443 | HTTPS | Очередь печати, статусы, пульс, обнаружение, проверка принтера |
| Локальная сеть: Moonraker | 7125 | HTTP | Загрузка файла, старт печати, состояние |
| OctoPrint, PrusaLink | 80, 443 | HTTP/HTTPS | То же |
| Bambu Lab | 8883 | MQTT + TLS | Команды и отчёты принтера |
| Bambu Lab | 990 | FTPS | Загрузка `.3mf`/`.gcode` |
| Creality | 9999, 80 | WebSocket, HTTP | Команды и файл |
| Anycubic | 9883, 18910 | MQTT, HTTP | Паспорт, команды, файл |
| FlashForge | 8898, 8899, 19000 | HTTP, UDP | Команды, файл, поиск в сети |
| Elegoo | 3030, 3000 | WebSocket, HTTP | SDCP-команды и файл |
| Обнаружение (UDP-бродкаст) | 48899, 52700 | UDP | Поиск принтеров в подсети |

Порты принтеров нужны только внутри локальной сети мастерской: наружу агент
открывает единственное соединение — HTTPS на `tridi-print.ru`. Если в цеху
стоит строгий файрвол, достаточно разрешить исходящий 443 и обращения к
адресам принтеров.

## Что стоит знать перед установкой

- Агент видит всю локальную сеть, к которой подключён компьютер: обход
  (`SCAN_NETWORK`, кнопка «Найти принтеры») стучится в адреса подсети. Это
  осознанное действие мастера, а не фон: по умолчанию обход выключен, а
  повторный запуск возможен только по кнопке.
- `TriDiAgent.exe` не подписан сертификатом code signing (это платная услуга),
  поэтому Windows SmartScreen может показать «Неизвестный издатель». Сборка из
  исходников (`python build_exe.py`) — способ проверить файл самому.
- Токен в `.env` — такой же секрет, как пароль. Файл не пересылайте и не
  выкладывайте; в git он не попадает (`.gitignore`: `.env*`, исключение —
  образец `.env.example`).
- Агент не хранит историю печати: после удаления `temp/` и `.env` на диске не
  остаётся данных о заказах.
- Агент устойчив к пересборке сайта: пока сервер поднимается, он пишет «CRM
  недоступна (нет связи), повтор через 10 секунд...» и продолжает опрос, а
  запущенные печати идут дальше — падение сайта не останавливает принтеры.
